# Документация проекта: project_recommender_system

В этой папке содержится документация по проекту: установка, архитектура и описание API.

- `INSTALL.md` — шаги по установке и запуску проекта.
- `API.md` — описание доступных HTTP эндпоинтов и примеры запросов.
- `ARCHITECTURE.md` — обзор архитектуры, структура проекта и описание ML-модуля.

Начните с `INSTALL.md` для локального запуска и тестирования.

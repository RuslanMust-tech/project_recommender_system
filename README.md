# project_recommender_system

Полный проект системы рекомендаций для продуктовой витрины (FastAPI + SQLite + ML-пайплайн).

Документация проекта находится в папке `docs/`.

Краткие команды:

- Запуск разработческой версии:
```
python run.py
```
- Альтернативно, через uvicorn:
```
./app/.venv/bin/uvicorn app.main:app --reload --port 8001
```

Откройте `docs/` для подробной информации по установке, API и архитектуре.

Для наполнения базы данных меню используйте первый закоменнтаренный скрипт из файла test_api.py

Для заполнения заказами используйте
```
# uv run --project app python3 app/scripts/seed_orders.py --rows 500 --users 20
```
